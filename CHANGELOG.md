# Changelog

## 0.1.1 (law as of 20 October 2026)

The project moved to the termsmith organization. The repository is now termsmith/user-agreements and the
documentation is at https://termsmith.github.io/. The plugin marketplace is now called `termsmith`; install with
`claude plugin marketplace add termsmith/user-agreements` and `claude plugin install user-agreements@termsmith`.
If you installed 0.1.0 through the plugin marketplace, remove the old marketplace with
`claude plugin marketplace remove user-agreements-skill` first. The skill's content is unchanged.

## 0.1.0 (law as of 20 October 2026)

First release. Drafts terms of service, EULAs, subscription and auto-renewal terms, privacy and cookie notices,
acceptable use policies, B2B data processing agreements, EU withdrawal information with the model form and the German
Impressum, for the EU (Germany as reference state) and the US (federal, California and New York in full, other state
privacy laws as a matrix). Hand-over with annotations, open points and an implementation register.
