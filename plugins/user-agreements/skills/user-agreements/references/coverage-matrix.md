# Coverage matrix

Law as of: 2026-10-20

A cell says covered (with the file), flag only, or not covered. Covered means a merged reference
file states rules for that topic in that jurisdiction group. Flag only means a reference file
raises the topic as an open point or a narrow carve-out without stating the rule in full. Not
covered means no reference file in this skill reaches that topic for that jurisdiction group.

California and New York in full means the instruments in their own files: for California, `us-states/ca-arl.md`,
`us-states/ca-ccpa.md`, `us-states/ca-caloppa.md` and `us-states/ca-civil-code.md`; for New York,
`us-states/ny-gbl-527a.md`. Every other California or New York topic in the table above (formation and assent,
standard terms control beyond unconscionability, warranties, liability beyond exculpatory clauses, licensing,
children, platform and user content, dispute resolution beyond the Consumers Legal Remedies Act, choice of law) is
the US federal baseline from the table above plus a flag to check state-specific law separately: no reference file
in this skill merges a California or New York statute reaching those topics.
