# Privacy note

This site is a set of static pages hosted on GitHub Pages.

- GitHub receives each request for a page and may log your IP address for security purposes. GitHub's handling of
  that data is described in the
  [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
- The site sets no cookies and runs no analytics or tracking.
- It loads no fonts, scripts or images from other servers.
- Search runs in your browser, on an index that is part of the site.
- If you switch between the light and the dark color scheme, your browser keeps that choice in its local storage on
  your device. It is not sent anywhere.

When you use the skill, your requests are handled by Claude Code under its own terms. This site and the repository
receive nothing from it.

For questions about this site, open an issue in the
[repository](https://github.com/nghorbani/user-agreements-skill/issues).
